# محادثة إنجليزي — تطبيق تعلّم الإنجليزية بالمحادثة الصوتية الحية

تطبيق أندرويد شخصي (للاستخدام الفردي فقط) لتعلّم الإنجليزية عبر محادثة صوتية حية مع Gemini، مبنية على سيناريوهات مكتوبة مسبقًا. الواجهة بالكامل بالعربية، والمحتوى التعليمي بالإنجليزية.

---

## 1. كيف يعمل التطبيق

1. تضيف كلمات إنجليزية جديدة (من قوائم جاهزة أو يدويًا) وتحدد هدفك اليومي من صفحة **الكلمات**.
2. من صفحة **الحوارات**، تولّد حوارًا مبنيًا على كلمات اليوم، أو تختار سياقًا ثابتًا (مطعم، مطار، مقابلة عمل...).
3. تبدأ محادثة صوتية حية: التطبيق يتحكم بدوره بمن يتحدث، ويستمع لك، ويصحح نطقك عند الحاجة.
4. تتابع تقدّمك (الكلمات المتعلَّمة، دقائق المحادثة، جودة النطق) من صفحة **التقدم**.

كل البيانات تُخزَّن محليًا على جهازك فقط (IndexedDB) — لا يوجد خادم خلفي، ولا تسجيل دخول.

---

## 2. الحصول على مفتاح Gemini API

1. اذهب إلى [Google AI Studio](https://aistudio.google.com/apikey).
2. سجّل الدخول بحساب Google، ثم اضغط **Create API key**.
3. انسخ المفتاح.
4. افتح التطبيق → صفحة **الإعدادات** → الصق المفتاح في حقل "مفتاح Gemini API" → اضغط **حفظ المفتاح**.

> ⚠️ المفتاح يُخزَّن على جهازك فقط عبر IndexedDB، ولا يُضمَّن أبدًا في كود المصدر أو يُرفع إلى GitHub. لا تشارك ملف النسخة الاحتياطية (Backup) الذي يحتوي مفتاحك مع أحد — مع العلم أن ميزة التصدير في هذا التطبيق مصممة أصلًا لعدم تضمين المفتاح.

---

## 3. رفع المشروع على GitHub

1. أنشئ مستودع (Repository) جديد فارغ على GitHub (بدون README أو .gitignore عند الإنشاء، لأنها موجودة هنا بالفعل).
2. من داخل مجلد المشروع على جهازك، نفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

استبدل `USERNAME/REPO_NAME` باسم مستودعك.

3. بمجرد الرفع (Push)، سيبدأ GitHub Actions تلقائيًا في بناء ملف APK — لا حاجة لأي إعداد إضافي.

---

## 4. تنزيل ملف APK الناتج

1. افتح مستودعك على GitHub.
2. اذهب لتبويب **Actions** أعلى الصفحة.
3. ستجد أحدث تشغيل باسم **Build Android APK** — اضغط عليه.
4. انتظر حتى تكتمل كل الخطوات (علامة ✔ خضراء).
5. في أسفل صفحة التشغيل، ستجد قسم **Artifacts** يحتوي ملفًا باسم `english-live-app-debug-apk` — اضغط عليه لتنزيله كملف مضغوط (zip) يحتوي ملف الـ APK.
6. انقل ملف الـ APK إلى هاتفك (عبر كابل، Google Drive، أو أي وسيلة)، ثم افتحه لتثبيته.

> ملاحظة: هاتفك يحتاج للسماح بـ"التثبيت من مصادر غير معروفة" (Install unknown apps) لأن هذا التطبيق غير منشور على متجر Google Play (فهو للاستخدام الشخصي فقط).

### إصدار مُوقَّع عبر GitHub Releases (اختياري)

إذا أضفت وسمًا (Tag) عند الدفع، مثل:

```bash
git tag v1.0.0
git push origin v1.0.0
```

فسيقوم Actions تلقائيًا بإرفاق نفس ملف الـ APK ضمن صفحة **Releases** بالمستودع أيضًا، ليسهل الوصول له لاحقًا.

---

## 5. البنية التقنية

- **الواجهة:** HTML + CSS + JavaScript خالص (بدون إطار عمل)
- **التخزين المحلي:** IndexedDB
- **الرسوم البيانية:** Chart.js عبر CDN
- **الصوت الحي:** Gemini Live API عبر WebSocket مباشرة من المتصفح (WebView)
- **التغليف:** Capacitor (`@capacitor/android`)
- **البناء:** GitHub Actions (`.github/workflows/build.yml`) — يُنشئ مجلد `android/` تلقائيًا عبر `npx cap add android` عند كل تشغيل، ثم يبني الـ APK بـ Gradle

### هيكل الملفات

```
├── www/                        ← كل ملفات الواجهة (تُنسخ إلى تطبيق أندرويد)
│   ├── index.html
│   ├── css/
│   └── js/
│       ├── db.js                ← طبقة IndexedDB
│       ├── word-lists-data.js   ← قوائم الكلمات الجاهزة
│       ├── fixed-scenarios-data.js
│       ├── scenario-generator.js ← توليد نص الحوار (Gemini نصي)
│       ├── gemini-live.js       ← التكامل مع Gemini Live API
│       ├── voice-orb.js         ← مؤشر حالة الصوت البصري
│       ├── charts.js
│       └── ui.js                ← منطق الواجهة والتنقل
├── capacitor.config.json
├── package.json
└── .github/workflows/build.yml
```

## 6. أسئلة شائعة

**التطبيق لا يستجيب صوتيًا؟**
تأكد من: (1) إدخال مفتاح API صحيح، (2) منح إذن المايكروفون، (3) اتصال إنترنت مستقر، لأن Gemini Live API يحتاج اتصالًا مباشرًا بالخادم.

**هل يمكن نشر التطبيق على Google Play؟**
هذا المشروع مُعدّ للاستخدام الشخصي فقط، ويحتوي مفتاح API يُدخله المستخدم يدويًا بدون أي طبقة أمان خادمية — لذلك غير مناسب للنشر العام دون تعديلات إضافية (مثل نقل الاتصال بـ Gemini API إلى خادم وسيط).

**كيف أعدّل تصميم الألوان أو الخط؟**
كل الألوان والمقاسات معرّفة كمتغيرات CSS في `www/css/tokens.css` — عدّل القيم هناك وستنعكس على كامل التطبيق تلقائيًا.
